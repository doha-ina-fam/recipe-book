# 우리집 레시피

기존 홈페이지 파일을 이 폴더의 파일로 교체해 사용하세요. 시작 파일은 `index.html`입니다.

## 이번 업데이트

- 총 394개 레시피 (148개 추가, 중복 2건 통합)
- 카테고리에서 휴대폰의 브라우저 뒤로가기를 누르면 메인 화면으로 이동
- 레시피 목록: 이미지 없이 한 줄에 이름과 좋아요 버튼
- 재료를 선택하고 수량을 확인한 뒤 장바구니에 추가
- 수량 미기재 재료는 팝업의 수량 입력칸이 비어 있음
- 상단 우리집 레시피·장바구니 탭 고정
- 장바구니는 같은 브라우저·기기에 저장되며, 다른 레시피의 재료도 각각 누적
- 장바구니 수량 수정·개별 삭제 지원
- 목록 끝의 텍스트 변환 버튼으로 재료 나열 및 자동 복사

HTTPS 또는 localhost에서 자동 클립보드 복사를 사용할 수 있습니다. 브라우저가 자동 복사를 제한하면 변환된 텍스트를 직접 선택해 복사할 수 있습니다.

장바구니와 좋아요는 브라우저 저장소를 사용합니다. 사이트 주소를 바꾸거나 브라우저 데이터를 삭제하면 기존 저장 내용이 표시되지 않을 수 있습니다.

재료 분량이 출처에서도 없거나 표기가 서로 다르면 임의로 확정하지 않았습니다. 원본과 다른 레시피로 대체한 항목은 출처 안내에 표시되어 있습니다.
